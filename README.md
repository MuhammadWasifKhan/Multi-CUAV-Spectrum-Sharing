# Multi-CUAV Spectrum Sharing
## Overview
This repository provides MATLAB simulation code for the research paper:
**Interference-Aware Joint Resource Optimization for Multi Cognitive UAV Spectrum Sharing Networks**
The study investigates interference-aware resource optimization for multiple cognitive UAVs operating over licensed and unlicensed spectrum bands.
## Proposed Schemes
- **AI-IBPC:** Adaptive Interference-Aware Intra-Band Power Control.
- **IA-RSS:** Interference-Aware Reserved Subchannel Selection.
## Available MATLAB Code
### Flight Time vs. Average Sum Rate
File: `AI_IBPC_IA_RSS_Flight_Time_vs_Average_Sum_Rate.m`
This simulation evaluates the average sum rate of AI-IBPC and IA-RSS under different UAV flight durations.
